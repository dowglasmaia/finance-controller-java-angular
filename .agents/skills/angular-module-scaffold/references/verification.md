# Validação do módulo

Escolha verificações proporcionais à mudança e aos scripts existentes no projeto.

- Rode a verificação de tipos e de templates configurada pelo Angular.
- Rode os testes unitários ou de componentes afetados.
- Verifique rotas, parâmetros e estados visíveis quando a jornada os alterar.
- Teste erros do contrato e campos inválidos quando houver formulários ou mutações.
- Rode o build de produção quando configuração, rotas, dependências ou integração puderem afetá-lo.

Não alegue que uma jornada está validada se apenas os tipos foram compilados. Quando uma verificação não for executada, informe o motivo e a limitação.
